Design direction // Telos

An operations console, not a to-do list

A job search run properly is a campaign with a pipeline, a conversion rate and a set of open fronts. Every competitor renders that as a task list. This treats it as an instrument panel: dense, calm, and readable at a glance.

What follows is a mockup, not a build. Nothing here is wired up. It exists so the direction can be argued with before any code is written.

What changed and why Met and missing sit side by side instead of stacked, which is what makes the gap legible at a glance. The verdict is stated in words next to the number, because 74 means nothing to someone who has not been told that most resumes are rejected. Certifications become chips ranked by impact rather than a bulleted list of equals.

On futuristic The reflex reading is neon on black, which is the single most templated look in software right now and would date within a year. What actually reads as advanced is instrument-grade precision: hairlines instead of shadows, tabular numerals, one accent held in reserve, density handled calmly. Closer to a glass cockpit than a sci-fi film.

What this costs

Two honest paths, and one correction first.

Telos is still a Streamlit app Moving to AWS changed where it runs, not what it is. The design ceiling has not moved at all. Everything above assumes one of the two paths below.
PathEffortWhat you actually get
Streamlit, pushed hard
Custom CSS, SVG icons replacing emoji, real components instead of st.metric		 2–3 days Perhaps 65% of the visual gain. The palette, type and density above are all reachable. The board is not, without a custom component. Every click still reruns the whole script, so it keeps the half-second lag that stops it feeling like an app you work in.
React and FastAPI
The rebuild already in your roadmap		 5–9 weeks All of it, plus instant interaction, drag between columns, and a keyboard layer. Your EC2 box and Caddy already serve this with no infrastructure change: static frontend, proxied API, same instance.
Hybrid
Streamlit shell, one custom React component for the board		 1–2 weeks The board and its interactions become real while the rest stays Streamlit. Genuinely the middle option, and it doubles as a way to learn React on something small before committing to the rewrite.
The part worth deciding first Not which path, but whether the interface is what is actually holding Telos back. That is answerable from the admin panel now rather than by taste. If people arrive and leave without returning, the interface is a plausible cause and this work is justified. If they never arrive at all, weeks spent here would be weeks not spent on the thing that is.
